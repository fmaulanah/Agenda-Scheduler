# CSG Agenda Scheduler

> Internal web application for managing Agenda schedules and employee attendance.

## 📸 Preview

[Dashboard Screenshot]

## ✨ Features

- 📊 Agenda dashboard
- 📅 Agenda schedule management
- 🪪 RFID attendance
- 🔄 Offline attendance queue
- 📤 Attendance upload
- 📋 Attendance history
- 📱 Responsive mobile interface
- 📊 Agenda statistics
- 📥 Excel attendance export

## 🛠️ Tech Stack

React • Vite • Material UI • Recharts • Axios • Day.js
